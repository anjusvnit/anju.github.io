# Dr. Anju Academic Website

## Files
- index.html — main webpage
- style.css — webpage design
- images/profile.jpg — profile photograph

## Free hosting with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository, e.g. `anju-website`.
3. Upload `index.html`, `style.css`, and the `images` folder.
4. Open Settings → Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select `main` and `/root`, then Save.
7. GitHub will provide a public website link.

Important: keep the folder structure exactly as provided so the profile photo loads:
images/profile.jpg
